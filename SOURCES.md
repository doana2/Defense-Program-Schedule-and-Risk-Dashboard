# Source references

Official sources researched for this portfolio. Program names, tasks, durations, resources, risks and results are synthetic.

- [GAO Schedule Assessment Guide, GAO-16-89G](https://www.gao.gov/products/gao-16-89g), including [full PDF](https://www.gao.gov/assets/gao-16-89g.pdf): integrated schedules, critical path, float, risk analysis, baseline control and Appendix VII's discussion of the DCMA 14-point assessment. The implementation's exact screening populations and simplifications are defined in METHODOLOGY.md.
- [Microsoft Project XML schema reference](https://learn.microsoft.com/en-us/office-project/xml-data-interchange/project-xml-data-interchange-schema-reference?view=project-client-2016): interchange structure, not a promise of native desktop compatibility.
- [Microsoft PredecessorLink](https://learn.microsoft.com/en-us/office-project/xml-data-interchange/predecessorlink-element?view=project-client-2016): dependency records.
- [Microsoft LinkLag](https://learn.microsoft.com/en-us/office-project/xml-data-interchange/linklag-element?view=project-client-2016): lag stored in tenths of a minute.
- [Microsoft Type element](https://learn.microsoft.com/en-us/office-project/xml-data-interchange/type-element-multiple-parents?view=project-client-2016): dependency type values FF=0, FS=1, SF=2, SS=3.
- [Tableau packaged workbooks](https://help.tableau.com/current/pro/desktop/en-us/save_savework_packagedworkbooks.htm): packaging workbook definitions with local data files.

No proprietary schedule, real defense program information, résumé content or employer endorsement is included.
